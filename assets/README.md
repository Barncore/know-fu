# README image

`i-know-kung-fu.gif` is the moment in *The Matrix* (1999) when Neo (Keanu Reeves) opens his eyes after the knowledge upload. It's there for the "I know kung fu" reference that gives the project its name, and it has no subtitles.

The owner supplied the GIF on 29 September 2026. It's 400 × 200 pixels, and its bytes and animation are untouched. The README centres it under the title at an 800-pixel display width, twice its native size, capped by the reader's screen. Where it was originally downloaded from wasn't recorded.

Worth keeping in mind for any future release: this is third-party film imagery, not Know Fu artwork, and it wouldn't be covered by any license chosen for the code. Keep its provenance separate when reviewing a public release.
