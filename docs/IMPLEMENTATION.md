## Architecture decisions

- Canonical records and complete Markdown accounts retain ownership. Navigation is a derived view of authored fields; missing summaries are explicit.
- Preserve the existing packet retrieval interface and evaluator for reproducible comparison. Progressive reading is an additive versioned interface.
- Separate optional graph exploration from mandatory scope, lifecycle, qualification and prerequisite checks. Turning exploration off must not turn caveats off.
- Return provenance references without automatically loading their bodies. Exact supporting revisions remain readable and current restrictions still apply.
- Scope filtering happens before titles, summaries, topic memberships or counts are exposed.
- Section locators bind the release, exact record revision and body hash. Section content is explicitly partial, while full-account reads remain available.

Setup, operation, component responsibilities and troubleshooting remain in the [README](../README.md) and [maintenance guide](MAINTENANCE.md). Behavior evidence and limits belong in [VALIDATION.md](VALIDATION.md). The installed skill describes both reading routes and the revised ingestion protocol; packet retrieval remains the routine-answer default.

## Current build evidence

The final full regression run after the reading, ingestion and evaluator changes passes 107 tests, with none skipped. Focused tests cover low-ranked exceptions, inherited primer caveats, source scope, exact historical reads, release-bound sections, current withdrawal, new material-link invalidation, staged reassessment integrity, batch reading, budgets, compact MCP presentation and resumption. Further regressions distinguish a judgment's assessed issues from prerequisites, prevent passage bodies receiving an authored-summary ranking bonus and preserve unfinished source stages during a rebase. These are engineering fixtures, not evidence of domain expertise.

A refreshed native Codex session successfully read seven fictional accounts through the constrained MCP reader. Four synthetic hidden-file reads were denied, as was a tool request attempting to override the fixed scope. A separate fixed-packet probe also denied four native file reads. The receipts bind the runtime policy and state configuration; a mismatched state binding was rejected before any evaluation model call. Actual reported input usage includes repeated context; these probes are isolation evidence, not efficiency benchmarks or exhaustive security assessments.

Additional grader source text is opt-in per run: its source refs or exact extract hashes, destination and authorization are frozen. This boundary was added after automatic approval review rejected unconditional addition of source text. The acceptance work uses public papers and fictional fixtures. Existing private research is not an implied grading payload.
